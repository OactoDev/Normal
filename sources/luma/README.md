# Luma snapshots

- **URL:** https://luma.com/nightshift-london
- **Refresh:** from repo root run `./scripts/pull-luma.sh`

Outputs:

- `latest.md` — most recent fetch (HTML stripped to text)
- `snapshots/YYYY-MM-DD.md` — dated copy for diffs

After pulling, update [SCHEDULE.md](../../SCHEDULE.md), [digest/LIVE.md](../../digest/LIVE.md), and [digest/CHANGELOG.md](../../digest/CHANGELOG.md) if anything changed.
