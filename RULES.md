# Rules and constraints

Official sources: [Luma](https://luma.com/nightshift-london) and host email. This file is a team cheat sheet — if anything conflicts, Luma/email wins.

## Team and eligibility

- **Team size:** 1–4 people.
- **In person only;** 18+.
- At least one team member must be at **Sunday demos** to win.
- Solo hackers can match at kickoff.

## Code

- **Project code written during the event** (from kickoff Fri 19:30).
- Ideas and research beforehand are fine; open-source libraries and your own tooling are fine.
- **Every project must route LLM calls through Mubit.**

## Submission

- **Sunday 10:00** — submissions close / code freeze.
- **Sunday 10:30** — judging round 1 (expo).
- **Sunday 12:30** — finalist demos on stage.

## What to build (brief)

Route LLM calls through Mubit; show corrections becoming model updates for a **recurring task**. Pick a track:

1. **Recurring tasks** — extraction, triage, support replies, review, routing.
2. **Own your intelligence layer** — closed vs task-adapted open model; quality, cost, latency.
3. **Fast refresh** — changing workload; model updates keep pace.

Top 3 prizes judged across all tracks.

## Judging (25% each)

1. Use of Mubit — correction → model update in demo.
2. Usefulness — real recurring task.
3. Technical execution — works under questions.
4. Demo — clear, live, on time.

## Prizes (reference)

- $65k cash pool ($15k / $10k / $5k + $35k AI credits) + $1.5M Mubit credits for accepted hackers.
- Early bird: first 50 accepted at check-in get $50 OpenAI API credits.
